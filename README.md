# Skills for founders who build on agents

Claude Skills for people running a business, not a codebase — equity, offers, funnels, hiring, operations.

Maintained by [Vitalii Matvieiev](https://www.matvieiev.com). Скіли для підприємців українською та англійською.

## Install

```bash
npx skills add vitalii-matvieiev/skills
```

Or install a single skill:

```bash
npx skills add vitalii-matvieiev/skills/slicing-pie
```

Skills work in Claude Code, the Claude desktop and web apps, and anywhere else that reads the `SKILL.md` format.

## Free skills

| Skill | What it does |
|---|---|
| [slicing-pie](slicing-pie/) | Splits startup equity between co-founders by actual contribution instead of a handshake 50/50. Calculates slices, sets the freeze event, covers good/bad leaver rules. |
